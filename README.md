# Adaptive-FSM
Code and data for the simulations of quantum state estimation with adaptive Fisher-Symmetric measurements. The ´PureState´ and ´SlightlyMixedState´ files contains the code and data for the simulation of the estimation of pure states and slightly mixed states respectively. This data was used for the analysis of the adaptive Fisher-symmetric measurements estimation protocol shown in _"Near-optimal pure state estimation with adaptive Fisher-symmetric measurements"_ work.
